### Persisted settings and mission-end transition

The source trace for the active booleans and Depth of Field transition is now complete:

1. `GlobalContext.Awake` obtains `Settings`, then calls `Settings.Load()` before `Apply()`. `Settings.Load()` calls `performance.Load()` between controls and graphics.
2. `SerializablePerformanceSettings.Load()` reads `Application.persistentDataPath + "/performance.dat"` through the source `Serializer`. A missing file falls back to a new default object; a deserialization exception clears `performance.dat` and restores defaults. Its `Save()` writes the same path and then invokes `onChanged`.
3. The `Settings.Performance` setter overwrites the live object and calls `Save()`. `UIPerformanceSettings.OnEnable` deserializes the loaded object into the three camera toggles; `OnDisable` calls `Save()`. Its listeners invoke the matching camera-grain, camera-bloom and camera-blur changed events.
4. `InteriorCamera.Start` calls `InitializeSettings()`. That copies the loaded `Graphics` FOV settings and sets `NoiseAndGrain.enabled`, `BloomOptimized.enabled`, and `CameraMotionBlur.enabled` from the loaded performance settings, then subscribes to all three change events. This confirms user-persisted settings can select the first two effects independently of the prefab's disabled component flags.
5. The Depth of Field component is outside this performance-toggle chain. Its authored prefab state is disabled. The successful Mission 01 outcome sequence calls `Mission.EndMission`, which calls `MissionEndMenu.Show`; the latter gets `Mission.InteriorMode` and calls `interiorCamera.EnableDepthOfField(true)` before activating the panel. `EnableDepthOfField` assigns the cached component's `enabled` flag.
