# PhysX implicit hinge spring and capsule prerequisites

This extends the isolated kernel introduced by PR #30. It remains **outside the live game's imports** and does not claim unchanged original physical ArmController execution, original capsule/hierarchy import, original Unity solver parity or native trajectory comparison.

Use a PhysX D6 joint with the three translations and two swing axes locked and only twist free/limited. This retains hinge degrees of freedom while supplying the implicit force-based twist drive missing from PxRevoluteJoint. Targets convert degrees to radians around the explicit joint X frame; source frame construction must preserve Unity's zero-at-start rest angle. Properties and enablement remain separate: setting a spring does not enable it. Original ArmController's 500/10/current-angle settings now have a real physical backend operation rather than an exception. Native Unity stiffness/damping trajectory equivalence remains unverified.

Capsules now use source radius/height/direction/center and physical mass/inertia. Source Unity Y/Z capsule axes map to PhysX's X axis; source coordinate reflection, linear/angular damping, gravity, kinematic state and Rigidbody constraint bits are implemented. Freeze-position locks apply to the physical center of mass: an offset body origin can move under rotation while its center remains locked. Numerical contracts explicitly check the recovered lower-arm capsule (mass 4, radius .05, height .34, center -.015/-.16/-.1, constraint 8).

Local Chromium passes **31** contracts: original 22 force/coordinate/hinge checks plus enabled implicit spring convergence, hold-current-angle, independent enablement, invalid coefficient rejection, capsule center/mass and frozen center-of-mass Z. The focused workflow runs the same contracts in Chromium and WebKit and preserves exact-SHA private evidence. Do not claim WebKit passed until the actual run finishes. No new full .NET WASM compilation is justified by this isolated, unimported engine change.

References: Unity 2017.2 HingeJoint.spring target/rest/enable contract: https://docs.unity3d.com/2017.2/Documentation/ScriptReference/HingeJoint-spring.html ; PhysX 5.6.1 D6 drives, hinge frames and radian units: https://nvidia-omniverse.github.io/PhysX/physx/5.6.1/docs/Joints.html . No explicit time-step spring integrator or invented gameplay controller is substituted.
